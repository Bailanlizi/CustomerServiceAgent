1. submit_refund_application 未自动注入 working memory（order_sn/reason_detail 仍由 LLM 自由声明）— 工作记忆字段只用作 prompt 提示，工具调用参数仍由 LLM 编造，违反 codex "能力注册表 + 前置校验" 的原意。

### 关键技术发现

- **LangGraph InjectedState 不支持点路径**：tool_node.py:1394 `injected_args[tool_arg] = state[state_field]` 直接索引，不支持 `collected_slots.user_confirmed`。降级方案：在 AgentState 顶层加 flat 字段 `user_confirmed`，prepare_turn 从 `collected_slots.user_confirmed` 提升到顶层，persist_turn 反向同步回 collected_slots（持久化真源仍为 collected_slots）。
- **InjectedState flat 字段 + Optional 默认值**：`Annotated[bool | None, InjectedState("user_confirmed")] = None` 让 state 缺值时不会抛 Pydantic 校验错误，前置校验里返回友好提示。
